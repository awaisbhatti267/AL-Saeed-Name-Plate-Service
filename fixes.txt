           cause silent bugs and confuses linters.
  Fix:     Renamed export from `page` to `HomePage`.

  Issue:   `import React from 'react'` was present. Since React 17+
           the JSX transform is automatic — this import is redundant.
  Fix:     Removed the unnecessary React import.

  Issue:   Contact component was imported directly from
           `./contact/page` — a route-level page being used as a
           reusable component. This violates separation of concerns.
  Fix:     Now imports `ContactForm` from `@/app/components/ContactForm`
           (the new dedicated component — see FIX #4).

  Issue:   Both Home and About sections had 26 identical repeated
           lorem ipsum paragraphs. Placeholder content was excessive.
  Fix:     Replaced with concise, meaningful real content (3 paras
           each) relevant to AL SAEED Name Plate Service.

  File:    src/app/page.jsx

FIX #4 — contact/page.jsx
  Issue:   File contained the full form markup directly, with no
           submit handler — the Submit button did nothing on click.
           Also had `import React` unnecessarily.
  Fix:     Simplified to a clean route shell that imports and renders
           `ContactForm`. All logic now lives in the component.

  Before:

  After:

  File:    src/app/contact/page.jsx

FIX #5 — Navbar.jsx
  Issue:   `navLinks` array was defined inside the component body.
           This means it gets recreated on every render (wasteful).
           It also caused a stale closure risk inside the `useEffect`
           scroll listener, which had an empty dependency array `[]`
           but referenced `navLinks` from the outer scope.
  Fix:     Moved the array outside the component as a module-level
           constant named `NAV_LINKS` (uppercase = constant convention).
           Updated all 3 references inside the component:
             - useEffect scroll handler
             - Desktop nav links map
             - Mobile dropdown links map

  File:    src/app/components/Navbar.jsx

FIX #7 — globals.css
  Issue:   Fixed navbar (h-16 = 4rem) causes anchor-linked sections
           to scroll and hide behind the navbar when clicking nav
           links like #home, #about, #contact.
  Fix:     Added `scroll-padding-top: 4rem` to the `html` element.
           This is a native CSS property that offsets scroll targets
           so they appear below the navbar correctly.

  Before:
    @import "tailwindcss";

  After:
    @import "tailwindcss";
    html {
      scroll-padding-top: 4rem;
    }

  File:    src/app/globals.css
